# Branmarker EN

3D box viewer for **Branmarker** (D.O., 1992, PC-98), with the soundtrack and the English translation patch.

**[Open the site](https://delacannon.github.io/branmarker-en/)** (18+)

- 3D box: drag to orbit, wheel to zoom, `Space` to turn it, `L` to switch lighting
- Soundtrack player with a spectrum that reacts to the music
- 20 tracks to download as VGM
- English patch: drop your own disk images A, B, C and E (`.hdm`) on the page, patched copies are saved. Nothing is uploaded and your originals are not changed

The patch contains no game data: you need your own copy of the game.

## Run it

```sh
pnpm install --ignore-workspace
pnpm dev
```

The built site lives on the `gh-pages` branch.
